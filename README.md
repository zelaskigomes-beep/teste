# Proteção da Informação com Python

Projeto desenvolvido com base nos conteúdos da unidade Start by Alura.

## Objetivos

- Implementar criptografia por substituição.
- Desenvolver funções de hash.
- Criar um sistema de autenticação.
- Calcular combinações de senhas.
- Simular tentativas de força bruta em ambiente controlado.
- Aplicar boas práticas de segurança da informação.

## Tecnologias utilizadas

- Python
- Biblioteca hashlib
- Biblioteca secrets
- Biblioteca hmac

## Conteúdos estudados

1. Criptografando informações
2. Criptografando letras
3. Refinando a cifra
4. Hash
5. Hash aprimorado
6. Autenticação segura
7. Combinações
8. Ataque de força bruta

## Conclusão

O projeto demonstra conceitos básicos de criptografia,
proteção de senhas e segurança da informação utilizando Python.
